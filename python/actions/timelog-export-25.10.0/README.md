# Timelog Export ⏱️📊

一个用于导出 ftrack 用户工时（Timelog）报告的 Action。支持按日期与项目过滤，生成可下载的 `.xlsx` 报表，并可自动保存当前导出设置到本地，适合制作周报/月报与项目核算。

## 主要特色 ✨

- 支持按一个或多个项目进行过滤， 也可一键勾选 `All Projects` 作为查询范围 ✅
- 日期范围可选，留空即代表以 “所有日期” 作为查询范围 📅
- 支持半开放日期过滤：仅填写`From`或仅填写`To`也生效 ⛓️
- 数值列采用两位小数格式（`0.00`），汇总更规范 🧮
- 导出 Excel 报表，包含汇总与用户维度拆分 📊
- 所导出的 Excel 报表布局保持和 ftrack 用户工时报告页面布局一致 🎨
- 自动保存当前导出设置到本地，并按用户名隔离保存 🔐
- 健壮兜底：历史设置缺失或字段无效时自动使用当前界面值 🛡️

## 使用方法 🚀

1. 在 ftrack 中选择一个或多个项目。
2. 触发 “Timelog Export” Action。
3. 在界面中：
   - 选择 `From` / `To`（格式为 `YYYY-MM-DD`，全留空代表以 “所有日期” 作为查询范围， 也可只填一行日期）。
   - 观察 `Current selection`（列举当前所选所有项目名）。
   - 可选 `All Projects` 忽略当前所选的项目，从所有项目获取工时记录。
   - 可选 `Use My Last Settings` 忽略当前界面上的所有配置，复用上次成功导出时的配置。
4. 点击提交后，稍等片刻，在弹出的 Job 中点击下载生成的 Excel 文件。

## 导出后的 Excel 报表样式说明 📁

- 主标题区显示 `Timelog report for <所选项目名>`（或 `All Projects`）。
- 抬头区显示 `Hours Tracked`（总登记工时）、`Projects`（相关项目数）、`Users`（相关用户数）、`Date Range`（日期范围）。
- 用户明细区：展示每位用户的 `Total(Hours)`（总登记工时）、并按 `Billable`（可计费）与 `Non Billable`（非计费）分类。
- 数值展示：小时值统一为两位小数格式（`0.00`）。

## 历史设置与隔离 🧩

- 每次成功导出时，工具都会把当前的导出配置自动保存到本地。
- 保存路径：`../config/users/<username>/last_setting.json`（按用户名隔离）。
- 配置文件是明文， 用户可以直接编辑该文件，例如修改日期范围、项目名等，作为下次的导出预设。
- 当勾选 `Use My Last Settings` 提交时：
  - 仅在字段值有效时进行覆盖（支持日期为空字符串以清空过滤）。
  - 无效字段会跳过覆盖并保留当前界面输入（同时记录日志）。

## 注意事项 ⚠️

- 日期控件显示格式由浏览器/操作系统决定；提交值标准为 `YYYY-MM-DD`。
- 关于日期范围：
  - 在界面上仅填写 `From` 日期 ：`2025-11-01` → 所导出的报表`Date Range`会显示 `2025-11-01 - ∞`，代表范围是 “从该日到无限以后”。
  - 在界面上仅填写 `To` 日期 ：`2025-11-30` → 所导出的报表`Date Range`会显示 `∞ - 2025-11-30`，代表范围是 “从无限以前到该日”。
  - 在界面上两行都留空 → 所导出的报表`Date Range`会显示 `All Dates`，代表范围是 “所有日期”。
- 若历史设置文件缺失或损坏情况下使用 `Use My Last Settings` ，工具会自动依照当前界面值继续执行导出 （兜底设计）。
- 所需依赖请参考 `requirement.txt` 文件。

## 安装依赖 🧰

在动作目录中：

```bash
pip install -r requirement.txt
```

## 注册与运行 🧭

- 该 Action 基于 `ftrack-python-api` 与 `ftrack-action-handler` 注册。
- 成功注册后，当用户在界面上选择了一个或多个项目后，会在 ftrack 的右键菜单或动作列表中显示出“Timelog Export”。
